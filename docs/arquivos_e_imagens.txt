# Guia de Ativos, Imagens e Dimensões

Use este guia para personalizar a identidade visual da sua igreja no aplicativo.

## 1. Logo e Identidade
- **Logo Principal:** Usada na barra superior e telas de login.
  - *Caminho sugerido:* `/public/logo.png`
  - *Dimensão:* 512x512px (Quadrada) ou Proporcional (Transparente).
- **Favicon:** Ícone da aba do navegador.
  - *Caminho:* `/public/favicon.ico`
  - *Dimensão:* 32x32px.

## 2. Imagens de Fundo (Backdrops)
As imagens usadas no app (como no mural de orações, versículos e Dashboard) são buscadas dinamicamente via **Unsplash**.

Para alterar os temas de fundo dos versículos:
- Localize a constante `SHARE_BACKGROUNDS` em `src/App.tsx`.
- Lá você encontrará as URLs. Você pode substituir as URLs do Unsplash pelas suas próprias URLs (ex: do seu site ou Google Drive público).

## 3. Avatares Padrão
- Quando um membro não tem foto, o sistema usa as iniciais do nome ou uma imagem padrão.
  - *Site base:* `https://images.unsplash.com/...` para capas de ministério.

## 4. Dimensões Recomendadas
- **Banners de Eventos:** 1200x600px (Proporção 2:1).
- **Fotos de Membros:** 400x400px (Proporção 1:1).
- **Imagens de Capa de Células:** 800x400px.

## 5. Ícones e Ilustrações
O sistema utiliza principalmente a biblioteca **Lucide React** para ícones de interface.

- **Subpasta de Ícones:** Todos os ícones personalizados devem ser colocados em `/public/icons/`. Isso mantém o projeto organizado.
- **Ícone de Oração (Dinâmico):** O ícone de oração agora suporta dois estados (Normal e Selecionado).
  - *Normal:* `/public/icons/logo_oracao.png`
  - *Selecionado (Ativo):* `/public/icons/logo_oracao_active.png`
  - *Como funciona:* O sistema troca automaticamente a imagem quando o usuário clica na aba de Orações. Recomendamos usar uma versão colorida ou preenchida para o estado "active".

## 6. Como Alterar Imagens Fixas
1. Crie as pastas necessárias (ex: `public/icons`) se elas ainda não existirem no seu repositório Git.
2. Suba seus arquivos para a pasta correspondente.
3. Se for uma imagem de upload dinâmico (como fotos de membros), use a pasta `uploads/` do servidor.
